# ログインフローの動画

[動画を開く・ダウンロードする](teraland-login.mp4)（35秒・日本語字幕・無音）

ログイン開始、認証、認可コード取得、トークン交換、ID Tokenの検証、UserInfo取得を
実ChromiumとローカルのWorkerで実行した録画です。RPの画面と署名付きFederation文書は
録画用のテストfixtureです。公開Cloudflare上での録画ではありません。

録画対象はコミット `2690dcc` です。秘密鍵・パスワード・認可コード・トークンの値は
動画に表示していません。サインアップ機能は未実装です。

[字幕ファイル](teraland-login.ja.srt)も利用できます。
